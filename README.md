# Transportation Planning Project - Sharif University of Technology
This project focuses on transportation data analysis and modeling to understand travel patterns and support planning decisions. It includes data preprocessing, exploratory analysis, predictive modeling, and comparison of trip distribution approaches.

# What is done in this project 
This project focuses on the comprehensive analysis and predictive modeling of transportation and trip-related datasets. The repository documents a complete pipeline for processing travel data, from initial exploratory analysis to the implementation of machine learning models for decision support in transportation planning.

# Key highlights of the project
Data Preprocessing & EDA: Comprehensive cleaning of trip data, including handling missing values, outlier detection, and statistical analysis of key variables such as travel distance, location coordinates, and pricing.
Feature Analysis & Transformation: Identification and encoding of categorical variables alongside normality testing for key performance metrics.
Predictive Modeling: Development and evaluation of regression models (with a focus on Random Forest) to predict trip pricing accurately.
Distribution Modeling: Implementation and comparative analysis of various trip distribution models to better understand travel demand patterns.
